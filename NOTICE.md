# NOTICE


## AI assistance disclosure

This project was developed with AI assistance:

- **Code**: application source (React + TypeScript + raw WebGL) and the Python data-preparation and validation harnesses were drafted with AI assistance.
- **Data**: frozen data files were generated by AI-drafted harnesses from the cited primary sources (NASA PSI repository CSVs, NIST WebBook tables, Cantera YAML inputs), snapshotted 2026-11-14. Outputs were checked against the cited sources.
- **Imagery**: all flame visuals are deterministic procedural shader output. There is no AI-synthesized imagery. The four NASA photographs (GRC-2016-C-05051, iss040e021546, iss040e072900, iss040e086481) are used unmodified. Delivery screenshots and video are captures of the app output and are watermarked "AI-assisted simulation render - not experiment footage".
- **Runtime**: the application contains no machine-learning model and makes no external AI API calls. Search is deterministic extractive retrieval; the simulator is deterministic classical physics.
